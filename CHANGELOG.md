# Changelog

All notable changes are tracked here using semantic versioning while the project
is still in the `0.x` alpha line.

## 0.8.0 - 2026-07-05

### Onda 8 - Visible product finish

- Added provider setup/onboarding commands with secure key storage and validation.
- Added safe configuration status and budget/routing controls.
- Added model comparison through the guarded MCP bridge.
- Added SillyTavern group-chat rendering and MCP-only example assets.
- Added CLI status output for config, budget, hardware, contracts, and HITL.
- Migrated package metadata to PEP 621 with optional extras for MCP, memory, and observability.

## 0.7.0 - 2026-07-04

### Onda 7 - Day-2 governance

- Added budget enforcement and ledger-backed cost accounting.
- Added contract validation gates for bridge tools.
- Added runtime governance hardening used by later visible features.

## 0.5.0 - 2026-07-04

### Onda 5 - LLM execution loop

- Added canonical LLM gateway and capability registry.
- Added OpenAI-compatible provider adapter and provider fallback behavior.
- Connected leaf-node execution to real provider responses and artifact output.
- Added hardware profiling and append-only consumption telemetry.

## 0.4.0 - 2026-07-04

### Onda 4 - Repository hygiene

- Archived obsolete root reports and removed unrelated cloned material.
- Validated CLI entrypoint and repository layout.
- Reduced misleading exports and documented the operational source of truth.
